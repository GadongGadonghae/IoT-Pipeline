## 5. 진행 순서

1. `demo_reset.sql` 실행 → 확인 값이 모두 0
2. `cd sfaas/player` → `python player.py --config config_10min.json`
3. 90초 고장, 155초 복구는 자동 (수동으로 하려면 `--manual` 후 `f C-PR3` / `r C-PR3`)
4. 600초에 끝나면 3번 기대값과 비교
5. 다시 하려면 1번부터 (같은 날 리셋 없이 다시 돌리면 제품 번호가 겹쳐요)

**수집 연결 없이**: 1번 → (판정 백엔드 켜 두기) → `rehearsal_10min_data.sql` 실행 → 화면·집계를 기대값과 비교

## 6. 단순화한 부분

- 공정 사이 이동 시간은 0, 버퍼 크기 제한 없음
- 상태 이력에는 C-PR3 고장만 넣었어요. 뒤 공정의 대기(I)는 백엔드 판정으로 생길 부분이에요
- 도장 데이터는 도금욕 용액 측정값을 "제품이 도장을 마칠 때의 용액 상태"로 보고 제품 1개 = 1줄
- 슬리팅 6대는 시각·제품 번호는 재생, 측정값은 실제 인버터(A-SL) 1대의 16초 평균을 똑같이 써요
- 사건(불량·고장)은 세 길이 모두 같아요. 5·10분은 복구 뒤 생산이 이어지는 모습을 더 길게 보여 줘요
