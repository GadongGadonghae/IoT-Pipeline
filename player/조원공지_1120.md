## 1. 꼭 해야 할 것 (내 PC에서)

순서대로 해 주세요. 안 하면 로그인 후 저장이 막히거나 "권한을 알 수 없어요"가 떠요.

1. **코드 받기**
   - IoT-Pipeline: `git pull` (main)
   - Back-End: `fix/first-idle-and-actual-qty` 브랜치 받기
   - Front-end: `fix/demo-live` 브랜치 받기
2. **DB 업그레이드** (SQL Shell, postgres 계정)
   ```
   \c sfaas
   \i <IoT-Pipeline 폴더>/alter_v0.3.12.sql
   \i <IoT-Pipeline 폴더>/alter_v0.3.13.sql
   ```
   - v0.3.12: 시각 색인 추가 (데이터가 쌓여도 화면이 느려지지 않게)
   - v0.3.13: 계정 권한 코드 변경 + 시연 계정 2개 추가

3. **백엔드 다시 켜기** (`.\gradlew.bat bootRun`)
4. **브라우저 새로고침 → 다시 로그인** (예전 로그인은 권한 정보가 없어서 자동으로 풀려요)

> ⚠️ 판정 백엔드는 **DB 하나에 한 대만** 켜요. 다른 사람 DB에 붙을 때는 `sfaas.judge.enabled: false`.

## 4. 백엔드 API 변경 (프론트·백엔드 담당 참고)

- **U-08** `status`를 쉼표로 여러 개 (`D,DC`). 예전엔 `D,I,S`가 통째로 비교돼 0건이던 버그 수정
- **U-08** `status`에 `DC`를 넣으면 상태 이력의 통신 끊김 구간도 같은 모양으로 (eventId 음수, 메모 저장 불가). status를 안 보내면 예전처럼 S·I·D만
- **M-15** 설비별 사이클에 `ng` (그날 그 설비에서 공정 NG 폐기된 수, 프레스는 NG가 난 단)
- **R-04** 보고서 승인 (위 2장)
- 권한 없음 → **403 `FORBIDDEN`** (`docs/api-spec.md` "계정 권한" 표)
- 속도: 과거 데이터 10일치(약 100만 줄)에서도 실시간 API가 0.1초 안 (재공·제품 위치·설비 상태·코일 쿼리를 "오늘 것만" 보게, v0.3.12 색인)
- AI 보고서 모델 `gemini-3.8-flash`, 제한 시간 60초 (2.5-flash는 새 사용자에게 막힘)

## 5. 시연 데이터 (과거 기록 + 오늘 오전)

`tools/make_history.py`로 만들어요. 결과 SQL은 커서(수십 MB) Git에 없어요 → 각자 만들어요.

```
cd <IoT-Pipeline 폴더>\tools
python make_history.py 2026-11-24            ← 기준 날짜 전 3일(주말 포함) + 기준 날짜 오전
python make_history.py 2026-11-24 --days 1   ← 하루만
python make_history.py 2026-11-24 --no-morning  ← 오늘 오전 더미 빼기
```

- 하루: 08:00~19:00, 점심 12~13시 계획정지, 라인당 약 2,000개, 공정 불량 약 0.5%·비전 불량 약 1%
- **장비고장 하루 2~3건, 30~50분** → 앞 공정은 후공정 정지 대기, 뒤 공정은 재공부족으로 30분 넘게 (가동률 화면에서 잘 보여요)
- **기준 날짜 오전 08:00~12:00 가동 + 점심~13:00** 더미 (리허설·시연은 점심 뒤 시작한다고 봄). 제품 번호 5001~, 코일 501~
- 실행: SQL Shell에서 `\i <IoT-Pipeline 폴더>/history/history_<기준날짜>.sql`
  - 맨 앞에서 **기준 날짜 13:00 전 기록을 지우고** 새로 넣어요 (그 뒤 기록은 그대로)
  - **발표 당일에는 13:00 이후, 리허설 직전에 실행**해요 (오전에 백엔드가 쌓은 기록을 더미로 바꿈)

### 리셋 (`demo_reset.sql`)
- 이제 **오늘 13:00 이후 기록만** 지워요. 과거 며칠·오늘 오전 더미는 남아요
- 리허설 전에는 매번 실행 (안 하면 제품 번호가 겹쳐 측정값이 저장되지 않고 화면이 섞여요)
